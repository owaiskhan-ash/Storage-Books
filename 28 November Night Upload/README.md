# 28 November Night Upload

Ten children's books analysed from cover photographs and rendered as hyper-realistic
book marketing images for the 28 November night collection. Each render keeps the
original cover artwork, lettering and layout intact, brightens the cover slightly,
confirms the upright orientation of the source photograph, and stands the book
perfectly upright, dead-on and un-skewed as the hero of a 4:5 frame. Every image is a
single continuous scene: no compositing, no collage, no added text overlays.

Nine of the ten titles are rendered. The one licensed Marvel comic was declined by the
image content filter on its single permitted attempt and is skipped, as requested.
