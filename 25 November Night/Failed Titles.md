# Books that could not be generated

Marketing images for this set live in this folder (`25 November Night`). The titles below are
the ones that do **not** have a generated image, with the reason. File numbers are kept free
so a later run can drop the image in without renumbering anything.

## Refused by the image generator

| File | Title | Reason |
| ---- | ----- | ------ |
| 13 | My Big Book of Colouring | Content refusal — Disney characters on the cover |
| 14 | The Jungle Book | Content refusal — Disney characters on the cover |
| 18 | Mickey Mouse Clubhouse On the Go | Content refusal — Disney characters on the cover |

These were attempted exactly once and then skipped, as instructed. Retrying the same cover
produces the same refusal, so they need a different approach (for example a cover-only
product shot without the character artwork) if they are ever wanted.

## Not attempted — per-turn generation limit

| File | Title | Reason |
| ---- | ----- | ------ |
| 10 | Harry and the Robots | Turn's generation cap was reached before this title was attempted |
| 26 | Corduroy Goes to the Doctor | Never attempted — the cap was used up by two mirror retries |
| 27 | Kiss Hello, Kiss Good-bye | Never attempted — the cap was used up by two mirror retries |

These three were not refused; they simply ran out of generation slots in their turn and are
safe to retry as-is.

## Gaps in this folder

`10`, `13`, `14`, `18`, `26`, `27` have no image. Every other number from `01` to `37` is a
finished 1638 × 2048 render.
